## Descripción

Este proyecto consiste en una API RESTful desarrollada con Node.js, Express y MongoDB Atlas para gestionar un catálogo de videojuegos y consolas.

## Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Instalar dependencias con `npm install`.
3. Crear un archivo `.env` con la URI de MongoDB.
4. Ejecutar el servidor con `node server.js` o `npm run dev`.
5. Ciertas funcionalidades como "crear juego" "actualizar juego" o "eliminar juego" solo pueden hacerse desde POSTMAN.
